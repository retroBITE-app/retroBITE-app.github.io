ROADMAP

What's shipped and what's planned

retroBITE is in active development. This page tracks the features in the current build and the ones planned before the first public release.

Shipped
Library scanning per console
Pick from 130+ consoles and scan each folder for its accepted file types and BIOS files.
Identify & checksums
Name and size lookup first, then CRC32, MD5 and SHA1. Multi-disc games merge through cue sheets and .m3u playlists.
Metadata & artwork
Developer, publisher, genre, players and 23 artwork types from ScreenScraper, in your preferred region.
Ratings & shelf filters
Community ratings out of 100, with filters by genre, players, rating and status.
RetroAchievements sync
Hardcore and softcore unlocks, points and rarity, with a nightly hash index and unlocks synced every 15 minutes.
File layouts
Pick a folder structure per console: Open PS2 Loader, one folder per game, RetroArch, or keep the structure you already have.
Base shipped · console configs added over time
Console toolbox
Writes loader configs and art, renames files and builds .m3u playlists for the consoles that need them.
ROM uploads
Chunked uploads from each console’s shelf, placed where the console’s layout expects them.
SMB / FTP network shares
Samba (SMBv1 to SMB3) and vsftpd serve the library to consoles and loaders.
Hardware docs in Markdown
Repair logs, calibration notes and compatibility matrices by console, with the last 20 revisions kept.
Color schemes & scanlines
Five color schemes that recolor the interface and logo, plus optional CRT scanlines.
Live activity
Scans, hashing, artwork and syncs run on their own queues and update the page live.
Onboarding & accounts
A first-run setup where you choose your username and password and set up the basics of the interface. After that, sign in with username or email.
Docker Compose stack
Web app, MariaDB, Samba and vsftpd, started with a single script.
Conversion (Tools)
Convert disc images between CHD, CSO, ZSO, ECM, VCD, RVZ, WBFS and ISO using chdman, maxcso, ecm, cue2pops and nodtool. Options to verify the checksum after writing and keep the source file, with a conversion queue.
Base shipped · console configs added over time
Transfer
Copy games to a USB drive or SD card from the interface, or send them over SMB or FTP to consoles that support it.
Base shipped · console configs added over time
Global search
Ctrl + K opens one search for the whole app for fast navigation: games first, then pages, settings and individual settings tabs.
PlannedNEXT
BIOS archive
A place to store your BIOS files inside retroBITE. How it will work is still being worked out.
Housekeeping
Tidy the library: remove games whose files are gone, find and remove duplicates, and clear out other leftovers.
Public release
Publish the Docker image and add installation and configuration guides to the docs.

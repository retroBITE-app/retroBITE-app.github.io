Getting startedIntroduction

Introduction ​

retroBITE is a self-hosted collection manager for retro games. It organizes ROMs, disc images and BIOS files by console, identifies every file against known titles, adds metadata and artwork, and serves the library over your local network straight to real hardware. It runs as a Docker Compose stack on your own server.

Public beta

retroBITE is in public beta. Expect rough edges and frequent updates, and report issues on GitHub or Discord. The roadmap tracks what has shipped and what is planned next.

How it started ​

retroBITE was born out of necessity. What started as a hunt for a Docker setup to network-load games onto personal consoles quickly grew when the available projects fell short. A simple server script evolved into a full collection management hub.

Along the way, two veteran developers from different corners of the retro community joined forces. One needed a reliable way to serve games to real consoles over the network. The other needed a proper home for a growing collection, with every file identified, described and easy to find. Instead of building two tools, they built one: retroBITE.

What it does ​

  • Console library: choose from a catalog of 130+ systems and give each console its own folder. Only the consoles you own appear in your library.
  • Library scanning: each console folder is scanned for the file types and BIOS files that system uses, with game counts and identification progress per console.
  • File identification: files are matched by name and size, then by CRC32, MD5 and SHA1 checksums. Multi-disc games merge through cue sheets and .m3u playlists, and anything unmatched waits in Needs identifying with a best guess and a confidence score.
  • Metadata and artwork: developer, publisher, genre, players and up to 23 artwork types from ScreenScraper, with Libretro thumbnails as a fallback.
  • retroBITE score: a score out of 100 for each game, from LaunchBox community ratings and how many play it on RetroAchievements, with a rank across your library.
  • RetroAchievements: link your account to see each game's achievement set, with hardcore and softcore progress synced automatically.
  • Loader-ready layouts: per-console folder structures for Open PS2 Loader, RetroArch or one folder per game, plus a toolbox that writes loader configs, artwork and .m3u playlists.
  • Network shares: Samba (SMBv1 to SMB3) and FTP serve the library directly to modded consoles and loaders, and ps3netsrv streams PS3, PS2 and PS1 games to webMAN MOD.
  • Conversion and transfer: convert disc images between CHD, CSO, RVZ, WBFS and other formats, and copy games to a USB drive, an SD card or a network share.
  • Hardware docs: keep repair logs, calibration procedures and compatibility matrices in Markdown, filed by console, with revision history.
